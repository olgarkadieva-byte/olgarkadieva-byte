## Open-source tools

### [AI Impact Measurement](https://github.com/olgarkadieva-byte/ai-impact-measurement)

Find out what your AI tools actually changed.

- Adoption, task success, time saved, cost, ROI and payback for every AI tool
- Measured against a group that did not use the tool (difference-in-differences), with 95% ranges
- A **keep / fix / retire** verdict per tool, with a quality guardrail
- Python package plus an in-browser demo that uploads no data

[Live demo](https://olgarkadieva-byte.github.io/ai-impact-measurement/) · [Data contract](https://github.com/olgarkadieva-byte/ai-impact-measurement/blob/main/DATA_CONTRACT.md)

### [AI Governance Kit](https://github.com/olgarkadieva-byte/ai-governance-kit)

A free, framework-aligned toolkit for governing AI systems.

- 34 AI controls, including 8 for AI agents, mapped to the **NIST AI RMF**, **ISO/IEC 42001** and the **EU AI Act**
- A five-dimension risk scoring model and EU AI Act tier screening guide
- A tested Python package (`aigov`) with CI

[Website](https://olgarkadieva-byte.github.io/ai-governance-kit/) · [Notion version](https://smartailayer.notion.site/AI-Governance-Starter-Kit-3f0e47a9275080e480efd72a57a9442d)
